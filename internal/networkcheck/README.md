# 可选本地代理检查

`Run(ctx) Report` 仅供用户显式选择后接入；当前没有自动调用。`Report.Error` 非空表示失败，`TrafficVerified` 只在本次实际代理请求验证后才为真。当前阶段只完成实现和配置/URL约束、fake gRPC 拒绝保护测试，未运行官方服务或真实本地代理检查，不代表实际代理链路已通过。

配置只包含 `127.0.0.1` 随机高位端口、随机认证的 mixed 入站与 direct 出站，启动前调用官方 `CheckConfig`。本地 fixture URL 和响应 token 都由程序创建；专用 HTTP 客户端只允许连接所选代理、不使用环境代理、不跟随重定向，不依赖外网。先确认未认证请求被拒绝，再验证认证请求返回 token 和 fixture 命中数。

没有系统代理、默认路由、DNS 或 TUN 配置；不调用 `SetSystemProxyEnabled`，不创建 TUN，也不修改当前网络设置。只有 daemon 为当前用户所有或可认领且核心为 IDLE 才继续；不使用 TakeOver，不替换已运行核心。仅在 StartService 成功且 ownership/startedAt 仍匹配时停止本次核心；失败清理使用独立短超时。Claim/start 会持久化 daemon 的所有权及本次配置。

官方 RPC 没有“仅空闲时原子启动”“按实例 ID 停止”能力；检查期间必须避免同用户其它客户端并发操作。随机端口从预留到核心绑定之间仍有竞争，冲突报失败，不通过改网络设置恢复。未能获得启动标记时宁可报告清理失败，也不停止可能属于其它操作的核心。

现有 `internal/smoke` 未修改；当前为了保持其稳定性保留独立生命周期保护实现。后续若两者同时维护，应再讨论抽取公共生命周期接口。
