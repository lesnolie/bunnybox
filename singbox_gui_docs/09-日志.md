# 09 日志（Logs）

## 9.1 可见性与数据源
- 侧栏“日志”始终可见。
- 日志订阅属于全局命令客户端（与状态、分组、Clash 模式共用同一连接管理），服务运行期间常驻，不随页面切换断开，因此离开页面后返回仍可看到期间的日志。
- 订阅 StartedService.`SubscribeLog`（每条含 level、message）；连接建立后调用 `GetDefaultLogLevel` 取默认级别。首次批次到达置“初始日志已接收”。
- 接收批处理：新日志先放入待处理队列，100 ms 窗口合并一次写入缓冲。
- 缓冲上限 3000 行，超出从头部丢弃，并累计“已丢弃计数”（总计数 = 已丢弃 + 当前条数，用于增量计算）。
- 服务停止并重新启动、或切换远程服务器时清空缓冲。

## 9.2 级别
| 值 | 名称 |
|---|---|
| 2 | Error |
| 3 | Warn |
| 4 | Info |
| 5 | Debug |
| 6 | Trace |

- “日志级别”选择（会话内，不持久化）：默认（跟随 `GetDefaultLogLevel`）/ Error / Warn / Info / Debug / Trace。
- 显示条件：`entry.level <= 有效级别` 且（搜索为空或 message 包含搜索文本，区分大小写）。

## 9.3 过滤管线
- 输入：缓冲、默认级别、选择级别、搜索文本（300 ms 防抖）、暂停状态、初始接收标志，任一变化重新计算。
- 暂停：进入暂停时对缓冲做快照，之后以快照为源；恢复时丢弃快照回到实时缓冲。
- 增量：级别与搜索未变时，只过滤新增的条目（新增数 = 总计数 − 上次已处理总计数）并追加；否则全量重算。
- 已过滤列表上限 3000；可见列表上限 1000，超过 1250 时一次性裁剪到 1000（减少头部删除导致的重排）。

## 9.4 布局
- 文本视图：只读、可选择、可复制；无背景（透出窗口/内容背景）；内容内边距 16；仅垂直滚动条（自动隐藏）；自动换行，行片段内边距 0。
- 字体：等宽 11（Cascadia Mono 11 DIP；见第 3 章）；默认颜色为主文字色。
- 每行解析 ANSI SGR 颜色（第 3 章 ANSI 色表），前景色按 WCAG 对比度 ≥ 4.5 相对 textBackground 调整：背景亮度 > 0.5 时按比例变暗，否则向白色提亮，10 次二分取满足阈值的最小调整量。
- 搜索命中：系统黄色背景高亮所有出现位置。
- 自动滚动：未暂停时，若全量替换或更新前视口底部距文档底部 ≤ 44 DIP，则更新后滚动到底部；用户上滚后不打断其阅读。
- 富文本构建在后台协程中进行，每 50 行检查取消；新的更新到来时取消未完成的构建。

## 9.5 空状态（居中）
- 已连接且已收到初始日志、但无可见行：“日志为空”。
- 已连接但尚未收到初始日志：旋转指示器。
- 正在使用远程服务器且未连接：“连接中...”（同时触发连接）。
- 本地服务未启动：“服务未启动”（同时尝试连接）。

## 9.6 工具栏
从左到右：
1. 搜索（magnifyingglass，“搜索”）：切换搜索框；隐藏时清空。搜索文本离开页面时保存到会话内存，返回时恢复并展开搜索框。
2. 暂停/恢复（pause.circle “暂停” / play.circle “恢复”）：切换自动滚动与快照。
3. “其他”菜单（line.3.horizontal.circle）：
   - “日志级别”（slider.horizontal.3）单选子菜单：默认 / Error / Warn / Info / Debug / Trace。
   - “保存”子菜单（square.and.arrow.down）：
     - “到剪贴板”（doc.on.clipboard）：复制已过滤日志全文（各行 message 原文以 `\n` 连接）。
     - “到文件”（arrow.down.doc）：写入临时文件后弹出保存对话框，默认文件名 `logs.txt`，类型纯文本；完成后删除临时文件；失败动作名 “export log file”。
     - “分享”（square.and.arrow.up）：写入临时文件 `Cache\logs-<时间>-<UUID>.txt` 后调用 Windows 分享界面（同 6.8）；结束后删除临时文件。
     - 准备文件失败动作名 “prepare log file”；准备过程中重复点击忽略。
   - “清除日志”（trash，破坏性）：取消暂停、清空本地缓冲与过滤状态，并异步调用 `ClearLogs`。
- Windows 文件名不允许冒号，临时文件名中的时间使用 `yyyy-MM-dd-HH-mm-ss`。
