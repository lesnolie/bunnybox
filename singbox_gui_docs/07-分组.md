# 07 分组（Groups）

## 7.1 可见性与数据源
- 侧栏“分组”仅在服务已连接（或已连接远程服务器，见 11.8）时出现。
- 进入页面时订阅 StartedService.`SubscribeGroups`（流式，每次推送完整分组列表）；离开页面取消订阅。
- 首次数据到达前显示居中文本“加载中...”。
- 分组字段：tag、type、selected、selectable、isExpand、items[]；条目字段：tag、type、urlTestTime、urlTestDelay（毫秒，0 = 未测）。
- 类型显示名：由 GUI 内置映射表把核心类型转为显示名（如 `shadowsocks`→Shadowsocks、`selector`→Selector、`urltest`→URLTest、`wireguard`→WireGuard 等），映射表与核心 `constant/proxy.go` 的 `ProxyDisplayName` 保持一致（列入第 16 章监视文件）。

## 7.2 布局
- 可垂直滚动；内容为 `LazyVStack(spacing:0)`，四周内边距 16；展开的分组以“置顶节头”形式呈现（滚动时节头吸顶）。
- 每个分组 = 卡片头段 + 卡片内容段，组间间距 14。
- 卡片背景：浅色 `#FFFFFF`、深色 `#1E1E1E`（textBackground 令牌，见第 3 章）；头段仅上圆角 16，内容段仅下圆角 16。

### 7.2.1 分组头
`HStack(spacing:8)`，内边距 上12 左16 下10 右8：
1. 组标签：headline。
2. 类型显示名：subheadline，次要色。
3. 弹性空白（最小 8）。
4. 条目计数胶囊：caption 等宽数字 semibold，次要色，内边距 2/8，背景中性色（浅 黑7%，深 白9%）。
5. 按钮组（`HStack(spacing:12)`，左外边距 12）：
   - 测速按钮：bolt.fill 图标（plain 样式，最小 28×28 命中区）；测速中替换为小号旋转指示器并禁用。
   - 展开/折叠：chevron.up（已展开）/ chevron.down。
- 点击头部空白区域亦切换展开。

### 7.2.2 折叠态：延迟点阵
- 内容段内边距 上2 左16 下14 右16。
- 每个条目绘制 11×11、圆角 4 的方块，颜色为延迟色；当前选中条目方块中心绘制 4×4 白色圆点。
- 列数 = max(1, ⌊(宽 + 4) / 15⌋)；列间距 = ⌊(宽 − 列数×11)/(列数−1)⌋（列数=1 时为 0）；行间距 4；高度 = 行数×11 + (行数−1)×4。
- 点击点阵切换为展开。

### 7.2.3 展开态：条目网格
- 自适应网格，列最小宽 170，行/列间距 10。
- 条目卡：
  - 第一行：条目标签（subheadline semibold，单行尾部截断）。
  - 第二行：类型显示名（caption 次要色）+ 弹性空白（最小 8）+ 延迟文本 `<n>ms`（caption 等宽数字 semibold，延迟色；仅 >0 时显示）。
  - 内边距 10/12；圆角 12；背景：选中为强调色 12% 透明度，否则窗口背景色；描边 1：选中为强调色，否则中性色；选中变化动画 easeOut 0.12s。
  - 行间距 4。
- 点击：仅当分组 selectable 且该条目未选中时，调用 `SelectOutbound(groupTag, outboundTag)`。
- 右键菜单：“URL 测试”（bolt.fill）→ 对该条目执行 `URLTest(tag)`。

### 7.2.4 延迟颜色
| 延迟 | 浅色 | 深色 |
|---|---|---|
| 0（未测） | 黑 7% | 白 9% |
| < 800 ms | rgb(61,129,104) | rgb(124,184,158) |
| 800–1499 ms | rgb(168,116,47) | rgb(211,164,94) |
| ≥ 1500 ms | rgb(194,94,50) | rgb(219,138,98) |

## 7.3 交互与乐观更新
- **选择**：立即在本地把分组 selected 改为新值，并记录“待确认选择”；后续推送中，若服务端值已等于待确认值则清除记录，否则继续以待确认值覆盖显示。失败弹错误（动作名 “select outbound”）。
- **展开/折叠**：本地立即切换（动画 easeInOut 0.25s），记录“待确认展开”，调用 `SetGroupExpand(tag, isExpand)`，推送对账逻辑同上；失败动作名 “update group expansion”。展开状态由核心持久化（cache file），重启后保持。
- **分组测速**：把组标签加入“测速中”集合 → `URLTest(groupTag)` → 完成后移出；失败动作名 “run URL test”。
- 推送列表与当前列表相等时不刷新界面，避免闪烁。
