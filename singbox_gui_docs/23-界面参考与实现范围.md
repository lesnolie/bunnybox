## 23.2 实现准则

| 区域 | 本轮目标 |
|---|---|
| 窗口 | MyGo原生布局；全高侧栏，正文独立统一工具栏；Windows系统按钮照常工作 |
| 导航 | 概览、分组、连接在上；日志、配置、设置在下；功能仍未实现时显示明确空态，工具入口可保留在菜单 |
| 浅色 | 灰侧栏、浅灰内容背景、白色大圆角卡片、蓝色选中导航 |
| 深色 | 蓝灰侧栏、深灰内容背景、深色卡片，文本层次清楚 |
| 概览 | 状态、连接、流量、累计流量四卡，以两列排列；模式、HTTP代理行及当前配置选择区 |
| 分组 | 分组头部和多列节点卡片；名称、协议、实际延迟、实际选中状态分别显示 |
| 图标 | 简洁一致的自绘SVG，避免用字符方框或齿轮文本代替图标；不随附未获许可的SF Symbols |
| 交互 | 现有本地配置CRUD保留，增加独立配置页；网络变更仍仅由用户明确操作触发 |

本章是用户最新视觉意图，优先于旧样板的默认按钮外观和侧栏数值。第3章的通用令牌、无障碍与平台差异继续适用，尺寸应结合参考截图的显示倍率和本机文字度量校准。

## 23.3 数据真实性和验收边界

- 生产界面只接收真实RPC结果。没有服务、未启动核心或流量统计不可用时显示空态/横线；不展示伪造节点、延迟或流量曲线。
- 截图单元测试允许显式注入fixture来验收有数据布局，文件名和测试代码须能区分fixture截图与真实运行截图；fixture不进入生产入口。
- 官方状态流首帧尚无有效速率时，速率显示横线；不能把初始化零值当作测得的0B/s。
- 本轮不启用系统代理、TUN或全局网络测试。不因视觉参考图中显示开启就自动开启。模式与HTTP代理接口现按23.6实现，仅用户显式点击才写入；测速等未接入功能继续禁用。
- 当前参考版本为文章1.14.0及用户提供的未标版本截图，核心仍锁定1.14.4。可以据此实现接近的外观，但不能据此宣称已完成1.14.4/macOS26所有页面的像素级验收。
- 验证重点：中英文浅深色布局、节点网格不溢出、本地配置真实保存与错误显示；保留普通用户运行窗口截图。后续再按锁定Apple提交核对差异。

- 不修改上游以绕过此问题，不分发 Windows 字体。后续需要进一步核对实际选中字体和小字号渲染路径；当前不能宣称字体或像素级视觉验收通过。

## 23.6 最新概览基准：上传/下载卡片与官方功能条件

本节按用户最新两张截图修订，优先于23.2中旧版“四统计卡＋固定HTTP代理行”。第一张紧凑速率卡只参考信息轻重；页面排列以第二张官方macOS截图为准，不混入FlClash的峰值、蓝色平滑曲线或其他仪表盘控件。

### 排列与字体层级

- 侧栏：概览、分组、连接、日志、工具、设置，顺序与最新截图一致。配置通过概览中的选择器和工具栏“其他→管理配置”进入，取消单独侧栏配置项。工具页面框架不代表工具功能完成。
- 第一行：上传、下载各一张大卡，标题17 DIP，当前速率26 DIP/600字重，累计量14 DIP/次级颜色。每张卡独立显示自己的速率、累计量和曲线，不再将上传下载挤入同一统计卡，不再单设“累计流量”卡。
- 曲线：最近60个真实采样，黑/白色折线、浅填充、虚线网格，纵轴按有效历史峰值的1.2倍缩放；不足两个样本只画网格，不制造曲线。未观测值显示横线。
- 第二行：状态（内存、协程）、连接（入站、出站）。
- 下方：仅在官方能力满足时显示HTTP代理、模式卡；配置卡置于最后，使用整行选择器、类型信息、下方编辑/分享操作。当前本地配置没有远程更新按钮，也不伪造Remote或最近更新时间。

### 官方源码核对

锁定的Apple子模块提交未变。依据 `ApplicationLibrary/Views/Dashboard/Cards/DashboardCard.swift`、`Overview/OverviewView.swift`、`Cards/UploadTrafficCard.swift`、`DownloadTrafficCard.swift`、`TrafficLineChart.swift`、`ProfileCard.swift` 及 `Views/NavigationPage.swift`：

- 官方默认顺序是上传、下载、状态、连接、HTTP代理、Clash模式、配置，相关卡片还可以由用户配置显示与顺序。本轮固定采用用户截图的主布局，尚未实现卡片排序/显隐编辑器。
- 状态、连接、流量仅在已连接时显示；配置始终显示。截图模式是上游特殊测试入口，不能据此在生产未连接时假造流量。
- **官方有HTTP代理**：核心已连接且 `systemProxyAvailable` 才出现，不是永久固定项。当前项目只在官方RPC报告可用时显示；点击前再次核对调用者所有权与核心运行状态，禁止认领服务或自动启动。
- Clash模式来自官方可用模式列表；只允许提交实际支持的值，当前模式不可用时不显示。
- 本地配置与远程配置的操作不同。当前只实现本地JSON；配置卡可选择、编辑、复制JSON分享，完整文件导出、二维码与远程订阅仍未实现，不能宣称与官方所有功能等价。

### 数据与验证边界

已新增持续只读 `SubscribeStatus` 接入：首帧无有效速率，后续帧才进入速率及曲线；退出、停止、刷新会取消旧订阅，按代数丢弃过期事件。订阅错误清空旧速率/曲线并显示错误，可通过检测服务重建订阅。配置修改仍不自动重启核心。

HTTP代理/模式写接口只由明确点击触发；本轮通过模拟gRPC核验所有权、能力、参数和拒绝路径，没有在宿主机切换系统代理、DNS、路由或TUN。持续指标也只在模拟流测试中验证，尚无本轮真实已连接流量证据。有曲线的布局截图是测试fixture，真实窗口截图是未连接状态，必须分别标注。
