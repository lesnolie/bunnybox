# 17 许可证与合规

## 17.1 本产品许可证
- 本产品整体以 **GNU General Public License v3.0 或更高版本（GPL-3.0-or-later）** 发布。
- 原因：
  - 本产品随附由 sing-box 核心源码原样构建的守护进程 `sing-box-daemon.exe`（GPL-3.0-or-later），GUI 以生成的 protos 与其通信，并在同一安装包中分发；
  - 界面、交互、文案与行为对 macOS 客户端（同为 GPL-3.0-or-later）进行一比一复刻，并使用其本地化文案，构成其衍生作品。
- **分发义务**：只要向任何第三方分发安装包或二进制（包括公开下载、内部分发给他人），必须：
  1. 以 GPLv3 向接收者提供完整对应源代码（GUI、构建脚本、安装器脚本、生成代码的生成器，以及修改过的依赖），可通过公开仓库链接提供，且须与所发布的二进制版本对应（按标签）；
  2. 随附 GPLv3 全文（安装目录 `LICENSE.txt`，“关于”面板链接）；
  3. 保留上游版权声明；
  4. 不得对接收者附加额外限制（如禁止再分发、禁止逆向）。
- 仅个人自用、不分发时不触发上述义务。

## 17.2 附加条款：名称与关联
sing-box 与 Apple 客户端许可证附带条款：衍生作品未经事先同意不得使用其名称或暗示与其关联。

### 17.2.1 随附未修改守护进程带来的固定名称
本产品不修改守护进程，因此以下名称由上游代码决定，无法由本项目更改：

| 名称 | 出现位置 | 决定方 |
|---|---|---|
| `sing-box-daemon.exe`，`version` 输出 “sing-box-daemon version X” | 安装目录 `resources\daemon\` | 守护进程（构建脚本默认输出名；守护进程按此名定位自身） |
| 服务名 `sing-box-daemon`，显示名 “sing-box Service”，描述 “Privileged service for sing-box”，事件日志来源 `sing-box-daemon` | 服务管理器、事件查看器 | 守护进程注册服务时写入 |
| 管道 `\\.\pipe\ProtectedPrefix\Administrators\sing-box`、worker 管道前缀 `sing-box-worker.` | 系统内部 | 守护进程 |
| GUI 可执行文件名 `sing-box.exe` | 安装目录、任务管理器 | 守护进程只接受此文件名的 GUI（2.6、2.9） |
| 安装包版本资源 `ProductName` = `sing-box` | 安装包属性 | 守护进程 `InstallUpdate` 只接受此产品名（12.5；可放弃，见下） |
| 守护进程错误消息中的 “sing-box” 字样 | 错误对话框详情 | 守护进程 |

另有沿用 sing-box-for-desktop 约定、技术上可以改名但为保持一致而沿用的名称：注册表键 `HKLM\SOFTWARE\SagerNet\sing-box`、守护进程数据目录 `C:\ProgramData\sing-box-daemon`、应用数据目录 `%APPDATA%\sing-box`。

### 17.2.2 处理规则
- 上述固定名称属于技术标识，用户可在服务管理器、任务管理器、文件属性中看到。是否构成“使用其名称”需要作者确认，列为 A-10 的一部分。推荐默认：发布前向作者说明本项目随附未修改守护进程，并就上述技术标识与安装包 `ProductName` 取得书面同意；未获同意前不公开发布二进制。
- 可自主决定的展示名称（窗口标题、托盘提示、开始菜单快捷方式名、安装包文件名、“应用和功能”中的显示名、发布仓库名、图标）由构建常量 `DisplayName`/`ProductID` 生成，未获同意前不得使用 “sing-box” 或官方图标（A-10）。
- 若作者不同意在安装包 `ProductName` 中使用 “sing-box”：`installerProductName` 改为本产品名，应用更新始终走 UAC 路径（12.5），其他功能不变。
- 若作者不同意 `sing-box.exe` 文件名或服务名：当前公开发布受阻，应报告负责人；不得自行启用附录 C 修改守护进程（A-29）。
- “关于”面板与 README 写明“基于 sing-box 核心，随附未修改的 sing-box 守护进程”，属于事实陈述，并注明“本产品不是 sing-box 官方客户端”。
- 与官方客户端互斥（15.10），安装器在检测到官方客户端时要求先卸载，不覆盖其文件。
