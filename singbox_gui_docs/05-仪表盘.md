# 05 仪表盘（Dashboard）

## 5.1 页面状态机

| 条件（按优先级） | 显示 |
|---|---|
| 服务未安装（`service status` 退出码 3，E-DAEMON-01） | 表单页（对应基线“安装系统扩展”）：表单按钮 lock.doc.fill + “安装服务”，点击执行第 15.2.3 节修复安装（UAC），完成后重新检测；分节脚注“sing-box 服务以系统权限运行核心。连接在退出应用后继续保持。” |
| 服务未运行（退出码 2，E-DAEMON-07） | 表单页：表单按钮 play.fill + “启动服务”，点击执行 15.2.3 修复启动（UAC），完成后重新检测 |
| 服务需要修复（守护进程版本与随附版本不一致、签名者不一致或证书过期，E-DAEMON-04/05/06） | 表单页：表单按钮 arrow.down.doc.fill + “修复服务”，执行 15.2.3 修复安装；E-DAEMON-06（证书过期）时按钮改为“检查更新”（12.5） |
| 处于远程控制 | 远程仪表（5.5） |
| 初始加载中 | 居中旋转指示器 |
| 其他 | 卡片网格（5.2） |

- 加载内容：配置列表、选中配置、系统代理状态、卡片配置。
- 主窗口重新激活时，若服务安装状态可能变化，重新检测（对应基线 controlActiveState 变化时 reload）。

## 5.2 卡片网格

### 5.2.1 卡片集合

| 卡片 | 枚举 | 管理表中名称 | 图标 | 默认顺序 |
|---|---|---|---|---|
| 状态 | status | Status | info.circle.fill | 3 |
| 连接 | connections | Connections | link.circle.fill | 4 |
| 上传 | uploadTraffic | Upload | arrow.up.circle.fill | 1 |
| 下载 | downloadTraffic | Download | arrow.down.circle.fill | 2 |
| 系统 HTTP 代理 | httpProxy | System HTTP Proxy | network | 5 |
| 模式 | clashMode | Clash Mode | circle.grid.2x2.fill | 6 |
| 配置 | profile | Profile | doc.text.fill | 7 |

- 默认全部启用。存储于偏好 `enabled_dashboard_cards`（字符串数组）与 `dashboard_card_order`（字符串数组）。
- 旧值迁移：`traffic` → `uploadTraffic`，`trafficTotal` → `downloadTraffic`；未知值丢弃；顺序中缺失的卡片追加到末尾。

### 5.2.2 显示条件

| 卡片 | 条件 |
|---|---|
| status、connections、uploadTraffic、downloadTraffic、clashMode | 服务 isConnected |
| httpProxy | 服务 isConnectedStrict 且 `GetSystemProxyStatus.available` 为真 |
| profile | 总是 |

### 5.2.3 排版
- 外层：可滚动，内边距 16（四周）。
- 按“已启用且可见”的顺序分行：相邻两张同组卡片合并为一行——上传+下载（traffic 组）、状态+连接（statistics 组）；其他卡片各占一行。合并规则：遍历顺序，当前卡片与下一张属于同一配对组时合为一行，否则单独一行。
- 行：`VStack` 间距 16；同行两卡 `HStack` 间距 16，等宽。
- 当服务状态不可切换（connecting/disconnecting）或正在 reasserting 时，整个网格禁用（不透明度 0.5，不响应交互）。

### 5.2.4 卡片通用组件
- **DashboardCardView**：`VStack(alignment: leading, spacing: 12)`，内边距 16，宽度填满，cardStyle（第 3.5 节）。
- **DashboardCardHeader**：`HStack(spacing: 8)`：图标（headline 字号，secondary 色）+ 标题（headline 粗体）。
- **DashboardCardLine**：`HStack`：标签（subheadline，secondary）+ Spacer + 值（subheadline，primary）。

## 5.3 各卡片

### 5.3.1 状态（Status）
- 标题“状态”，图标 info.circle.fill。
- 行“内存”：`Status.memory` 以 `byteformats.FormatMemoryKBytes(uint64(memory))` 格式化（直接传入字节数）；行“协程”：`goroutines`。
- 尚未收到首个状态时两行值显示“...”。

### 5.3.2 连接（Connections）
- 标题“连接”，图标 link.circle.fill。
- 行“入站”：`connectionsIn`；行“出站”：`connectionsOut`；未收到时“...”。

### 5.3.3 上传 / 下载（Upload / Download）
- 标题“上传”/“下载”，图标 arrow.up.circle.fill / arrow.down.circle.fill。
- 主值：当前速率 `FormatBytes(uplink)+"/s"`（全应用的 FormatBytes 定义为 `byteformats.FormatKBytes(uint64(n))`，直接传入字节数）（下载用 downlink），字体 title2，字重 medium。
- 副值：累计 `uplinkTotal` / `downlinkTotal`，subheadline secondary。
- `trafficAvailable` 为假时（核心未启用流量统计），速率与累计显示“...”，图表为空。
- **TrafficLineChart**：
  - 高 60，宽度填满；数据为固定 30 个采样点的历史数组，初值全 0；每收到一条状态消息移除首个、追加当前速率（状态订阅间隔 1 秒）。
  - 纵轴最大值 = max(max(数据) × 1.2, 1)；点值归一化后截断到 [0,1]，y = 高 × (1 − 归一化值)；x 按 (宽 /(点数−1)) 等距。
  - 网格：4 条水平虚线（y = 高 × i/3，i = 0…3），线宽 1，虚线 [5,5]，颜色 secondary @ 0.3。
  - 折线：线宽 2，圆端、圆角连接，颜色 primary；折线与底边闭合区域填充 primary @ 0.1。
  - 点数 ≤ 1 时只画网格。
  - 用 MyGo `Painter` 自绘。
  - 断开连接后历史重置为 30 个 0。

### 5.3.4 系统 HTTP 代理（System HTTP Proxy）
- 单行：Header（network 图标 + “系统 HTTP 代理”）+ Spacer + 开关（隐藏标签）。
- 开关初值来自 ManagedService.`GetSystemProxyStatus.enabled`；切换时调用 `SetSystemProxyEnabled(enabled)`；失败弹错误并回滚开关，动作名 “set system proxy”。
- 系统代理由守护进程设置 Windows WinINet 代理（核心 `set_system_proxy` 行为），GUI 不直接修改注册表。

### 5.3.5 模式（Clash Mode）
- 仅当 `GetClashModeStatus.modeList` 数量 > 1 时显示。
- Header：circle.grid.2x2.fill + “模式”。
- 选择器：
  - 若所有模式名称在一行可容纳（测量：每段文字宽 + 左右内边距 12，总宽 ≤ 卡片内容宽），使用分段标签：高 32，字号 13 medium；选中段为胶囊（圆角 12，primary @ 0.1 填充）；外框为 selectorBackground（圆角 12）。
  - 否则使用下拉菜单按钮：显示当前模式（13 medium）+ chevron.up.chevron.down（10 semibold，secondary），高 32，水平内边距 14，selectorBackground；点击弹出模式菜单（当前项打勾）。
- 切换：`SetClashMode(mode)`，并订阅 `SubscribeClashMode` 同步外部变化；失败错误动作名 “set clash mode”。

### 5.3.6 配置（Profile）
- Header 行：doc.text.fill + “配置”；右侧加号按钮（图标 plus，16，按钮 44×32，ActionIconButton 样式），打开“新建配置”工作表（第 6.4 节）。
- 无配置：显示“无配置”（Empty profiles，secondary）。
- 有配置：
  1. **ProfileSelectorButton**：整宽按钮，文字为当前配置名或“选择配置”（13 medium，primary）+ Spacer + chevron.up.chevron.down（10 semibold，secondary）；水平内边距 14，高 32，selectorBackground。点击打开“配置”选择工作表（5.4）。
  2. **信息行**（`HStack(spacing: 8)`）：类型图标（12，secondary）+ 类型名（caption，primary：本地/iCloud/远程）；远程配置额外显示 clock.fill（12，secondary）+ 最后更新时间相对描述（caption；“3 分钟前”“昨天”，完整单位风格，随界面语言）。
  3. **操作按钮行**（`HStack(spacing: 12)`，每个 44×32，图标 16，ActionIconButton 样式）：
     - pencil：编辑配置（打开编辑工作表，6.5）。
     - arrow.clockwise：立即更新（仅远程配置）；更新中图标持续旋转并禁用；失败错误动作名 “update remote profile”。
     - square.and.arrow.up：分享菜单（第 6.8 节）：保存文件、分享文件、保存 JSON 内容、分享 JSON 内容文件、以二维码分享 URL（仅远程）、以 QRS 码分享。
- 切换选中配置：写入偏好 `selected_profile_id`；若服务正在运行，置状态为 reasserting 并以新配置重新启动服务（停止→启动），完成后恢复。

## 5.4 配置选择工作表（Profiles）

- 工作表标题“配置”，最小 400×300，大尺寸。
- 列表：plain 样式，行间距通过行内边距上下 2、左右 16 实现，无分隔线，行背景透明。
- 行（ProfilePickerRow）：`HStack(spacing: 12)`，内边距 16，cardStyle：
  - 左侧 16 宽：普通模式为 checkmark（16 semibold，accent，未选中时透明度 0）；编辑模式为 line.3.horizontal（16 medium，secondary）拖动柄。
  - 中间 `VStack(spacing: 4)`：名称（body，primary）+ 信息行（同 5.3.6 第 2 项）。
  - 右侧：普通模式为 ellipsis 菜单（16，secondary，32×32；更新中替换为 0.8 倍旋转指示器）——编辑、更新（仅远程）、分享子菜单（同 5.3.6）；编辑模式为 minus.circle.fill（20，红色）删除按钮。
- 点击行（非编辑、非更新中）：选中并关闭工作表。
- 底部栏：分隔线 + 右对齐按钮“取消”（Esc，关闭）与“编辑”/“完成”（强调按钮，切换编辑模式，带动画）；背景 controlBackground。
- 编辑模式：拖动行重排（拖拽预览为行内容：类型/名称，宽度等于行宽，内边距 12/8，圆角 8）；删除即时生效，不二次确认；顺序写入每个配置的 `order` 字段。
- 编辑配置打开编辑工作表，最小 500×400。

## 5.5 远程仪表

- 远程连接已建立且未在重连中：显示与 5.2 相同的网格，但仅包含 status、connections、uploadTraffic、downloadTraffic、clashMode 五种卡片（按用户顺序与启用状态）；数据来自远程服务。
- 否则显示居中旋转指示器。
- 页面出现或窗口激活时发起连接。

## 5.6 仪表项管理工作表（Dashboard Items）

- 标题“仪表项”，最小 400×400。
- 列表行：line.3.horizontal 拖动柄（secondary）+ 开关（标签 = 卡片图标 + 名称）。profile 卡开关禁用且恒为开；禁用的行不透明度 0.5。
- 拖动柄重排顺序，变更即时写入偏好。
- 工具栏：“重置”（破坏性红色文字；清除 `enabled_dashboard_cards` 与 `dashboard_card_order`，恢复默认）与“完成”（Esc，关闭）。
- 关闭后仪表重新加载卡片配置。
