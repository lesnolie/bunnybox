## 最需要尽早决定的事项
1. **A-10 / A-26 名称同意**：随附未修改守护进程使 `sing-box.exe`、服务名等成为固定技术标识；未获同意前不能公开发布，安装包 `ProductName` 决定能否无 UAC 更新。
2. **A-29 备用方案启用条件**：取决于 M0 实机签名验证（20.5）；失败须报告阻塞，不授权修改后端。
3. **A-35 MyGo 进程形态**：守护进程对 GUI 进程的父子关系有硬性要求，M0 必须确认。
4. **A-28 / 证书与更新密钥保管**：首个发布前生成自签名证书与 Ed25519 密钥，落实机密与离线备份。
5. **A-34 自动发布放行策略**：每个候选的真实验证为硬性要求；按 22.4 落实草稿与晋级流程。
6. **A-23 按需启动“评估连接”语义**：Windows 上无法逐连接触发。
7. **A-14 USB/IP 驱动**：驱动签名决定功能是否可用。
