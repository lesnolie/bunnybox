# 01 概述与目标

## 1.1 产品定位

本应用是 sing-box 通用代理平台在 Windows 上的图形客户端。它负责：管理 sing-box 配置文件（本地与远程订阅）；通过 sing-box 官方特权守护进程以 TUN（wintun）或系统代理方式启动/停止 sing-box 核心；实时展示流量、内存、连接、日志与出站分组；提供网络诊断工具；常驻系统托盘。

本应用以 sing-box 官方 macOS 客户端为唯一产品基线：
- **功能一致**：基线中每一项用户可见功能在本应用中都有对应实现；仅依赖 Apple 专有系统能力且 Windows 无等价物的功能按第 15 章处理（映射、替代或省略，省略项在附录A记录原因）。
- **界面一致**：页面结构、控件种类与顺序、文案、图标语义、间距、圆角、配色、动画与 macOS 版一致；字体与图标因版权无法随附时使用第 3 章规定的替代品。
- **版本一致**：本应用版本号与 sing-box 核心版本号一致（例如 1.14.4），并按第 16 章在验证通过后跟随上游；Apple 界面基线另行记录，不以核心版本号代替界面对齐状态。

## 1.3 范围

### 必须实现
- 主窗口：仪表盘、分组、连接、日志、工具、设置六个页面，侧边栏导航与工具栏（第 4–11 章）。
- 配置管理：新建、导入（文件/链接/URL Scheme/.bpf）、编辑、内容编辑器（JSON 校验、格式化、补全）、远程更新与定时自动更新、导出与分享、二维码与 QRS、排序、删除（第 6 章）。
- 服务控制：启动、停止、重载；守护进程服务安装/修复/卸载；非网络特权模式（insecure mode）开关；工作目录管理（第 2、11、15 章）。
- 系统代理开关、Clash 模式切换、出站选择与 URL 测试（第 5、7 章）。
- 系统托盘：状态开关、分组子菜单、配置子菜单、实时速率显示（第 12 章）。
- 开机启动、后台驻留、单实例、`sing-box://` 协议与 `.bpf` 文件关联（第 4、6、12 章）。
- 远程控制：连接其他设备上启用 API 服务的 sing-box（第 11 章）。
- 工具：Tailscale、OpenConnect、OpenVPN、USB/IP、网络质量、STUN 测试、崩溃/OOM/功耗报告（第 10 章）。
- 应用更新：GitHub 发布检查、稳定/测试通道、签名与哈希校验、更新提示与安装（第 12 章）；发布由 GitHub Actions 跟随上游自动完成（第 22 章）。
- 多语言：英语、简体中文、繁体中文、俄语、波斯语（附录B）。

### 不在范围
- 修改 sing-box 核心或守护进程源码。守护进程按上游原样构建；M0 若失败，先排查证书与前端集成；仍不可行时报告阻塞。附录 C 仅作历史备选，未经产品负责人明确变更“官方后端不改”的目标，不得实施。
- 购买商业代码签名证书或接入第三方签名服务（可作为后续可选改进，见 21.6）。
- Apple 专有能力（iCloud Drive、Apple 设备间近场传输、App Store 评分等）在 Windows 上的复刻，按第 15 章与附录A处理。

## 1.4 术语

| 术语 | 含义 |
|---|---|
| GUI / 应用进程 | `sing-box.exe`，以当前用户身份运行的 MyGo 原生界面进程 |
| 守护进程 / daemon | 官方 `sing-box-daemon.exe`，以 Windows 服务 `sing-box-daemon`（显示名 “sing-box Service”）、LocalSystem 身份运行，内嵌 sing-box 核心，负责运行核心、TUN、系统代理，对外提供 DesktopService / StartedService / ManagedService |
| worker | 由 GUI 进程直接启动的 `sing-box-daemon.exe worker` 子进程，以当前用户身份运行，提供 ApplicationService（配置校验/格式化/Schema/配置编解码/独立测试/报告打包），并把 GUI 到守护进程的连接经认证后中继到守护进程管道 |
| 同签名者要求 | 守护进程只接受与自身 Authenticode 签名证书逐字节相同的 GUI 与 worker；本项目以自签名证书满足该要求（2.9、第 21 章） |
| 非网络特权模式 / insecure mode | 守护进程的设置项，开启后配置可使用与网络无关的特权能力；对应 DesktopService 的 GetSecuritySettings / SetInsecureModeEnabled |
| 配置 / Profile | 一份 sing-box JSON 配置及其元数据（名称、类型、远程 URL、自动更新设置） |
| 偏好 | 应用级设置项（第 13 章） |
| 基线 / 上游 | 第 1.2 节锁定的官方源码 |
| 卡片 | 仪表盘上的信息块 |
