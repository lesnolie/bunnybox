# 10 工具（Tools）

## 10.1 页面结构
侧栏“工具”始终可见。页面为分组表单（FormView），各分节按条件出现，从上到下：

| 分节 | 条件 | 条目 |
|---|---|---|
| 端点（Endpoints） | 存在 Tailscale / OpenConnect / OpenVPN 端点 | 每个端点一行导航链接 |
| 服务（Services） | 存在 USB/IP 服务器 | 每个服务器一行 |
| 网络（Network） | 总是 | 网络质量、STUN 测试 |
| 调试（Debug） | 未处于远程控制 | 崩溃报告、OOM 报告、功耗报告、“台湾旗帜可用” |

- 端点/服务行文字：同类只有一个时为类型名（“Tailscale”/“OpenConnect”/“OpenVPN”/“USB/IP”），多个时为 `类型: <tag>`。
- 图标：Tailscale point.3.filled.connected.trianglepath.dotted；OpenConnect / OpenVPN network.badge.shield.half.filled；USB/IP externaldrive.connected.to.line.below；网络质量 network；STUN arrow.triangle.swap；崩溃报告 ladybug.fill；OOM memorychip；功耗 battery.50percent。
- 报告行右侧显示未读数徽标（0 不显示）。
- Tailscale 行：有发送失败的 Taildrop 会话时右侧显示红色 exclamationmark.circle.fill，否则徽标为未读接收文件数。右键菜单“通过 SSH 连接”：只有一个可 SSH 的对等节点时为单项，多个时为同名分节列出各节点名。可 SSH 条件：在线、有 SSH 主机密钥、有 Tailscale IP。
- 端点/服务订阅：服务连接时开始订阅 `SubscribeTailscaleStatus`、`SubscribeOpenConnectStatus`、`SubscribeOpenVPNStatus`、`SubscribeUSBIPServerStatus`，断开时取消；同时启动本机 USB 提供者（10.6.3）。
- 页面内导航为详情列内推入（带返回），与第 4 章导航模型一致。
- 外部请求打开 Taildrop（通知点击，见 12.6）时：切到工具页并推入对应端点（或第一个端点）的 Taildrop 页。

## 10.2 网络质量（Network Quality）
标题“网络质量”。
- 分节“配置”：
  - URL：文本框，默认核心常量 `NetworkQualityDefaultConfigURL`；持久化 `nq_config_url`。
  - 串行（Serial）开关，持久化 `nq_serial`。
  - HTTP/3 开关，持久化 `nq_http3`。
  - 最大运行时间：30s / 60s 选择，持久化 `nq_max_runtime`。
  - 出站：仅服务已连接（或远程已连接）时显示导航行“出站 — <已选/默认>”，进入出站选择页（10.4）；服务断开时若正在测试则取消，并清空选择。
  - 测试运行中上述控件禁用。
- 分节“操作”：未运行显示“开始测试”（play.fill），运行中显示“取消测试”（stop.fill）。
- 开始前检测计量网络（MyGo `Network.Status().Metered`）：为计量时警告“计量连接 / 您正在使用计量连接，此测试将消耗大量流量。”按钮“取消”/“继续”（破坏性）。
- 执行通道：服务已连接 → StartedService.`StartNetworkQualityTest`（带出站标签）；未连接 → ApplicationService.`StartStandaloneNetworkQualityTest`（worker 内执行）。
- 分节“结果”（phase ≥ 0 时出现）：空闲延迟（timer，`<n> ms`）、下载（arrow.down.circle，FormatBitrate）、下载 RPM（arrow.down.to.line）、上传（arrow.up.circle）、上传 RPM（arrow.up.to.line）。
  - 值未出现：运行中且对应阶段活动时显示小号旋转指示器，否则 “-”。
  - 值出现且该阶段仍活动时，值左侧显示旋转指示器。
  - 完成后在值右侧显示置信度（caption）：高（绿）/ 中（黄）/ 低（红）。
  - 下载活动 = 阶段为下载，或（非串行且阶段处于下载与完成之间）；上传同理。
- 失败动作名 “network quality test”；测试过程中的错误回调直接显示错误消息。

## 10.3 STUN 测试
标题“STUN 测试”。
- 配置：服务器文本框（默认 `STUNDefaultServer`，持久化 `stun_server`）；出站行同 10.2。
- 操作：开始/取消测试。执行通道同 10.2（`StartSTUNTest` / `StartStandaloneSTUNTest`）。
- 结果：外部地址（network）、延迟（timer，`<n> ms`）；完成且服务器不支持 NAT 探测时显示“NAT 类型检测 — 服务器不支持”（exclamationmark.triangle），否则显示 NAT 映射（arrow.left.arrow.right）、NAT 过滤（line.3.horizontal.decrease），值文本由核心格式化，颜色：端点无关 绿 / 地址相关 黄 / 地址与端口相关 红。
- 失败动作名 “STUN test”。

## 10.4 出站选择页
- 标题“出站”；顶部搜索框（标签不区分大小写包含匹配）。
- 第一行“默认”（选中时右侧强调色 checkmark）。
- 订阅 StartedService.`SubscribeOutbounds`，每行：标签（单行）、第二行类型显示名（caption 次要）+ 延迟（caption 延迟色，>0 时）；选中行右侧 checkmark。
- 点击即选择并返回。

## 10.5 Tailscale
### 10.5.1 端点页
标题“Tailscale”或“Tailscale: <tag>”。端点消失时自动返回上一页。
- 分节“状态”：
  - 状态：8 DIP 圆点 + 状态文本；颜色 Running 绿、NeedsLogin/NeedsMachineAuth 橙、Starting 黄、其他灰。
  - Running 时：“本设备”（laptopcomputer）→ 本机对等节点详情，右侧显示设备名；有出口节点候选时“出口节点”→ 出口节点选择页，右侧显示当前出口节点名或“已禁用”。
  - Running 且有待接收文件或发送会话时：“Taildrop”（tray.and.arrow.down）行，右侧依次显示：失败红色感叹号 / 等待文件数 / “接收中” / “发送中”。
  - 有认证 URL 时：“打开认证 URL”（arrow.up.forward.app，用默认浏览器打开）、“以二维码打开认证 URL”（qrcode，工作表标题“认证 URL”）。
- 每个用户组一个分节（标题为显示名，空则登录名），列出对等节点行：8 DIP 圆点（在线绿/离线灰）+ 名称 + 第一个 IP（caption 次要）+ 徽章行（仅在线节点；caption2 胶囊）：“共享接入”（红）、“出口节点”（蓝）、“已过期”（红）或 30 天内到期“<相对时间>后过期”（灰）或“密钥过期已禁用”（灰）、“SSH”（绿）。
- 节点行右键“通过 SSH 连接”（有 SSH 主机密钥时）。

### 10.5.2 对等节点页
标题为节点名。
- 本机且（有网络名或非密钥认证）：分节“网络”——网络名行；非密钥认证时“退出登录”（破坏性，`TailscaleLogout`，失败动作名 “logout”）。
- 分节“Tailscale 地址”：MagicDNS（FQDN 去尾点）、主机名、各 IP（含 `:` 标 IPv6，否则 IPv4）；每行右侧复制按钮（doc.on.doc，复制后 1 秒内显示 checkmark）。
- 非本机且在线：分节“Ping”（节头右侧播放/停止按钮）：
  - `StartTailscalePing(endpointTag, peerIP)` 流；结果行：连接类型（直连 arrow.right “直接连接” / 中继 arrow.triangle.2.circlepath “对等中继连接” / “DERP 中继连接”）+ 右侧 `<n> ms`（headline）；直连显示“端点”，对等中继显示“对等中继”，DERP 显示“DERP 区域”。
  - 运行中且有结果：延迟折线图（高 80，最近 30 个样本，直连绿线、中继蓝线，右侧刻度 50 宽：max、2/3、1/3、0，max = ⌈最大值×1.2⌉ 且 ≥1，caption2 次要色）。
  - 错误红字；运行中无结果“连接中...”；无结果“无数据”。
- 分节“Taildrop”（可接收文件且端点可共享时）：发送区（10.5.4）。
- 分节“详情”：密钥到期（已过期/相对时间/已禁用）、操作系统、最后在线（离线时）、出口节点（活动/可用）、共享接入（是）、SSH（可用；macOS/Windows 为“通过 SSH 连接”导航按钮）。

### 10.5.3 出口节点选择页
标题“出口节点”；第一行“已禁用”，其后为候选节点（圆点 + 名称 + 第一个 IP），选中项 checkmark。选择调用 `SetTailscaleExitNode(endpointTag, stableID)`（禁用为空字符串），失败动作名 “set exit node”。

### 10.5.4 Taildrop
- 发送区（Send Zone）：虚线圆角框，square.and.arrow.up 图标 + “将文件拖放到此处发送，或点击选择”（caption 次要）；支持拖放（MyGo 拖放）与点击打开多选文件对话框；调用 `SendTaildropFiles` 流，按文件报告进度。失败动作名 “select files” / “receive dropped files” / “send files”。
- Taildrop 页（标题“Taildrop”）：订阅 `SubscribeTaildropInbox`，打开即 `MarkTaildropInboxRead`。
  - 分节“发送”：各会话各文件进度行（名称、进度文本 + “ · 发送至 <节点>”、进度条或不定进度、× 取消）。
  - 分节“接收”：接收中文件进度行（“来自 <发送者>”，× 调用 `CancelTaildropReceiving`）。
  - 分节“文件”：已接收文件行（名称、`<大小> · <相对时间>`），点击用默认程序打开（先 `DownloadTaildropFile` 到临时目录，显示环形进度 44×32）；“…”菜单：保存（保存对话框）、分享（Windows 分享界面）、删除（破坏性）。
  - 工具栏“其他”菜单：“全部删除”（破坏性）。
  - 发送失败会话：逐个弹出错误。
  - 错误动作名：“subscribe Taildrop inbox”、“cancel receiving file”、“delete received file”、“delete received files”、“download received file”、“save received file”。

### 10.5.5 SSH 连接
- 首次连接（或该节点未开启快速连接）弹出 SSH 选项工作表（最小 360×220，标题为节点名，工具栏“取消”/“连接”）：
  - 用户名（占位“必填”，默认记住的值或 `root`）；终端类型（占位 `xterm-256color`）。
  - “转发代理”开关（Windows：转发 Windows OpenSSH Agent 命名管道 `\\.\pipe\openssh-ssh-agent`；macOS 上的“仅独立版可用”说明不显示；A-03）。
  - 节头“SSH 选项”，节脚“可在应用设置中编辑终端配置以自定义终端外观。”
  - “记住 SSH 选项”开关（节头“快速连接”）：开启后把节点加入快速连接集合；节脚“启用后，可在工具中 Tailscale 条目和节点列表的**右键菜单**中快速连接此节点。”
  - 持久化：`tailscale_ssh_remembered_usernames`（stableID→用户名）、`tailscale_ssh_remembered_terminal_types`、`tailscale_ssh_quick_connect_peers`、`tailscale_ssh_forward_agent`。
- 快速连接节点直接打开终端。
- 终端窗口：独立窗口 880×560，标题为当前会话显示名；MyGo terminal 插件，`Conn` 接到 `StartTailscaleSSHSession` 双向流；工具栏会话菜单：“新建窗口”（macwindow.badge.plus）、复制当前会话、按节点新开会话；会话结束时显示横幅与原因文本及“关闭”按钮。
- 外观由“设置 → 终端配置”（11 章）提供字体、字号、主题（主题选择页按首字母分节，含“主题”分节）。

## 10.6 OpenConnect / OpenVPN / USB/IP
### 10.6.1 OpenConnect 端点页
- 分节“状态”：状态行（圆点 + 文本）；隧道信息：服务器、类型（Flavor）、传输、IPv4、IPv6、DNS（逗号分隔）、MTU、已连接（相对时间）。
- 分节“认证”（有挑战时）：横幅、消息；表单字段按类型渲染为选择器/密码框/文本框；按钮“继续”（无字段）或“提交”，提交中显示“验证中”；“取消”（破坏性，`CancelOpenConnectAuthChallenge`）。
- 浏览器认证：打开独立“认证”窗口，内嵌 MyGo web view（WebView2），独立持久会话（按 storageKey 隔离）；跟踪导航、响应头、Cookie，按请求的完成模式（回调 URL 匹配 / 指定 Cookie / 指定响应头）判定完成后 `SubmitOpenConnectAuthResponse`；网页 alert/confirm/prompt 以“网站消息”对话框呈现；加载失败在顶部显示错误条（exclamationmark.triangle.fill + 文本，callout）；“关闭”取消挑战。

### 10.6.2 OpenVPN 端点页
- 状态：状态行；服务器、网络、加密算法、IPv4、IPv6、DNS、MTU、已连接。
- 认证：“打开认证 URL”/“以二维码打开认证 URL”；挑战表单：消息、“到期”（剩余时间倒计时）、用户名、密码或密钥（明文/密文按挑战指定）、“提交”（验证中显示旋转）；有上次错误时弹出。`SubmitOpenVPNChallengeResponse` / `CancelOpenVPNChallenge`。

### 10.6.3 USB/IP 服务器页
- 标题“USB/IP”或“USB/IP: <tag>”；分节“设备”：无设备时“尚未共享设备。”；每个设备行：圆点（状态色）+ `<名称>:` + 状态文本（空闲/已连接/不可用），点击进入设备详情，右侧 xmark.circle 停止共享（仅本机提供的设备）。本机已提交但服务端尚未显示的设备显示“准备中”。
- 节脚（Windows 与 macOS 相同逻辑）：“使用 + 按钮共享本机的 USB 设备。”
- 工具栏“+”菜单“共享 USB 设备”：列出本机可共享设备（`<名称> (<VID:PID>)`），无则“没有可用的本地设备”。
- 本机提供者：GUI 通过 sing-usbip 的 Windows 后端（VBoxUSB 驱动，由官方构建脚本暂存于 `resources\daemon\` 并随守护进程一同安装）枚举本机设备，并经 StartedService.`ProvideUSBDevices` 双向流提供；错误动作名 “start USB/IP provider”、“list local USB devices”、“share USB device”、“stop sharing USB device”（待定 A-14）。
- 设备详情页（标题为设备名）：分节“标识”（产品、VID:PID、序列号、版本）、“连接”（总线 ID、后端、速度、总线/设备）、“类与接口”（设备类、配置数、各接口类三元组）。

## 10.7 调试：报告
报告由守护进程生成并保存在守护进程数据目录，经 DesktopService 列表/读取/标记已读/导出/删除。

### 10.7.1 列表页（崩溃 / OOM / 功耗）
- 行：10×10 未读蓝点（已读透明）+ 日期时间（未读 semibold）+ 第二行 caption 次要色：desktopcomputer “本机”（崩溃报告类型为卡死时追加 hourglass “卡死”）。
- 空时“空”；节头“报告”；节脚：崩溃“发生崩溃时您将收到报告。”；OOM“启用内存限制后，当服务内存超过限制时您将收到报告。您也可以手动触发报告收集。”
- OOM 页额外分节“设置”：
  - “启用内存限制”（说明：为服务提供软内存限制，服务会尝试多种处理以保持在此限制内。）`oom_killer_enabled`，默认关。
  - “内存限制”（启用时）：50 MB/100 MB/200 MB/300 MB/500 MB/750 MB/1 GB（FormatMemoryBytes），`oom_memory_limit_mb`，默认 50。
  - “终止连接”（说明：服务内存超限时关闭所有连接以释放内存。）`oom_killer_kill_connections`，默认关。
  - 任一改动后若服务运行则重启服务（失败动作名 “restart service”）。
- 功耗页额外开关“启用功耗报告”（说明：每次服务运行保存一份报告）`power_report_enabled`，默认关，改动后重启服务（Windows 报告内容见 A-07）。
- 工具栏：删除按钮（trash.fill，全部删除）；OOM 页“获取内存报告”（memorychip，服务未运行时提示“服务未启动”，失败 “trigger OOM report”）；崩溃页“其他”菜单含“崩溃触发”（ant.fill，仅调试构建）。

### 10.7.2 详情页
- 标题为报告日期（中等日期 + 短时间）。分节“文件”：文件列表，点击查看文本内容页（等宽、可选择；空时“空”）。
- 工具栏：分享（square.and.arrow.up）→ 报告分享工作表；删除（trash.fill）。
- 报告分享工作表（最小 360×240）：开关“附带日志”、“附带配置”；提示“日志和配置文件可能包含隐私内容，不应公开。”；“使用 age 为 Project S 加密”开关及说明；按钮“保存”（保存对话框）、“分享”、“取消”。打包由 ApplicationService.`ArchiveReport` 完成。
- 错误动作名：“save crash report”、“export crash reports”、“save power report”、“export power report”。

### 10.7.3 台湾旗帜可用
行“Taiwan Flag Available”（touchid 图标）：加载时显示“加载中...”，随后显示 `true`/`false`。判定：以系统 UI 字体 8 DIP 渲染 U+1F1F9 U+1F1FC，若渲染结果为空白/缺字形则为 false（A-02）。
