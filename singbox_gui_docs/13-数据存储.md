# 13 数据存储

## 13.1 目录布局

| 路径 | 内容 | 说明 |
|---|---|---|
| `%APPDATA%\sing-box\settings.db` | SQLite 数据库 | 偏好、配置元数据、远程服务器 |
| `%APPDATA%\sing-box\configs\config_<id>.json` | 配置内容 | UTF-8 无 BOM，原子写入 |
| `%APPDATA%\sing-box\terminal\fonts\` | 导入的终端字体 | 11.2.1 |
| `%LOCALAPPDATA%\sing-box\Cache\` | 缓存根 | “清除缓存”清空此目录 |
| `…\Cache\share\` | 分享/导出临时文件 | 第 6 章 |
| `…\Cache\logs\` | 日志分享临时文件 `logs-<时间>-<UUID>.txt` | 第 9 章 |
| `…\Cache\reports\` | 报告打包 zip | 第 10 章 |
| `…\Cache\taildrop\` | Taildrop 下载暂存 | 第 10 章 |
| `…\Cache\updates\` | 更新安装包 | 第 12 章 |
| `…\Cache\WebView2\<storageKey>\` | OpenConnect 浏览器认证会话 | 第 10 章 |
| `C:\ProgramData\sing-box-daemon\`（守护进程数据目录，可在自定义安装中更改，15.2.2） | 守护进程工作目录：守护进程设置 `settings.json`（非网络特权模式、语言）、服务所有者状态、核心工作文件（缓存文件、规则集缓存等）、崩溃/OOM/功耗报告 | 由守护进程创建与维护；ACL 受保护：所有者 SYSTEM，仅 SYSTEM、Administrators 与服务 SID（`NT SERVICE\sing-box-daemon`）完全控制。内部结构属上游实现，GUI 不直接读写，只经 DesktopService 访问（10.7、11.3） |
| 注册表 `HKLM\SOFTWARE\SagerNet\sing-box` | 安装布局：`LayoutVersion`=2、`ApplicationDataDirectory`、`DaemonDataDirectory` | 由安装器写入（2.6）；GUI 启动时读取 |

- 应用数据目录默认为 `%APPDATA%\sing-box`；自定义安装选择固定目录时，上表中 `%APPDATA%\sing-box\` 的内容位于该目录（`Cache\` 仍在每用户的 `%LOCALAPPDATA%\sing-box\Cache\`）。目录首次使用时创建，并设置 ACL：仅当前用户、SYSTEM、Administrators 可访问（配置可能含凭据）；固定共享目录的 ACL 由安装器设置（15.2.2）。
- 卸载默认保留以上数据；勾选“删除数据”时删除守护进程数据目录、应用数据目录（每用户默认目录时为当前用户的 `%APPDATA%\sing-box`）与 `%LOCALAPPDATA%\sing-box`，并删除注册表布局键。

## 13.2 SQLite 结构
使用 MyGo `plugins/sqlite`，WAL 模式，单写连接 + 读连接池。迁移按名称顺序执行并记录在 `migrations` 表：

| 迁移名 | 内容 |
|---|---|
| `initialize` | 建表 `profiles`（见 6.1，不含 autoUpdateInterval）、`preferences(name TEXT PRIMARY KEY ON CONFLICT REPLACE NOT NULL, data BLOB)` |
| `add_auto_update_interval` | `profiles` 增加 `autoUpdateInterval INTEGER NOT NULL DEFAULT 0` |
| `add_remote_servers` | 建表 `remote_servers(id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT NOT NULL, "order" INTEGER NOT NULL, url TEXT NOT NULL, secret TEXT NOT NULL DEFAULT '')` |

- `remote_servers.secret` 列保留但写入空串；真实密钥存凭据库（13.4）。
- 偏好值编码：字符串为 UTF-8 原文；其他类型为 JSON（布尔、整数、浮点、字符串数组、字符串映射、规则数组）。读取失败或缺失返回默认值；写入 nil 即删除该行。

## 13.4 敏感数据
- 远程服务器密钥、GitHub 令牌：存 Windows 凭据管理器（MyGo Secrets），目标名 `sing-box/remote-server/<id>`、`sing-box/github-token`。删除服务器时一并删除凭据。
- 配置内容可能含密码：不加密（与基线一致），依靠目录 ACL 保护。

## 13.5 并发与一致性
- 所有数据库写在单 goroutine 串行执行；配置列表变化通过事件总线通知各页面（配置卡、托盘配置子菜单、远程更新调度）。
- 同一配置的内容写入与远程更新互斥（按配置 ID 加锁）。
- 进程单实例（12.3）保证只有一个写者。
