# 08 连接（Connections）

## 8.1 可见性与数据源
- 侧栏“连接”仅在服务已连接（或远程服务器已连接）时出现。
- 进入页面订阅 StartedService.`SubscribeConnections{interval = 1e9}`（纳秒，即每秒），离开页面取消订阅。
- 客户端维护连接存储（`internal/model/connections`），按事件增量合并：
  - `reset = true`：清空存储。
  - NEW：插入完整连接。
  - UPDATE：`uplink = uplinkDelta`、`downlink = downlinkDelta`（即每秒速率），`uplinkTotal += uplinkDelta`、`downlinkTotal += downlinkDelta`。
  - CLOSED：设置 `closedAt`，`uplink = downlink = 0`；若事件带完整连接则以其替换。
  - 每次合并后淘汰关闭超过 5 分钟的连接。
- 显示前剔除 `outboundType == "dns"` 的连接。
- 时间字段为 Unix 毫秒。

## 8.2 过滤、排序、搜索
- **状态过滤**（持久化键 `connection_state_filter`）：全部(0) / 活动(1) / 已关闭(2)。页面初始值为“活动”，随后读取偏好覆盖；偏好不存在时读到默认值 0，即实际首次显示“全部”（与基线一致）。
- **排序**（持久化键 `connection_sort`，默认“日期”）：
  - 日期(0)：createdAt 降序，相同则按 id 字符串降序。
  - 流量(1)：uplink+downlink 降序，相同按 id 降序。
  - 总流量(2)：uplinkTotal+downlinkTotal 降序，相同按 id 降序。
  - 排序为稳定排序。
- **搜索**：按空格拆分为多项，全部满足才匹配：
  - `键:值` 形式：`network`（等于）、`inbound`（包含）、`inbound.type`（等于）、`source`（包含）、`destination`（包含）；未知键视为不匹配。
  - 普通项：destination 或 domain 包含该项。
  - 区分大小写。
- 搜索文本在离开页面时保存到会话内存（非持久化），再次进入时恢复并自动展开搜索框。

## 8.3 工具栏
- 搜索按钮（magnifyingglass，标签“搜索”）：切换搜索框显示；隐藏时清空搜索文本。搜索框位于窗口工具栏右侧（与 macOS `searchable` 外观一致：圆角输入框 + 放大镜 + 清除按钮）。
- 更多菜单（ellipsis.circle）：
  - 子菜单“状态”：全部 / 活动 / 已关闭（单选，勾选标记）。
  - 子菜单“排序方式”：日期 / 流量 / 总流量（单选）。
  - “关闭所有连接”（破坏性红色）：`CloseAllConnections`，失败动作名 “close all connections”。

## 8.4 列表
- 加载中：居中“加载中...”。
- 空状态（居中文本）：有搜索词时“没有匹配的连接”；否则按过滤：全部→“没有连接”，活动→“没有活动连接”，已关闭→“没有已关闭的连接”。
- 列表：垂直滚动、`LazyVStack`（默认间距 8），四周内边距 16（默认 padding）。

### 8.4.1 连接卡
卡片样式 cardStyle（第 3 章），内边距 16，整卡可点击，文字颜色为主文字色。
- 第一行（caption2 等宽粗体，下边距 4）：`<NETWORK 大写> <显示目标>` + 弹性空白 + 状态（“活动”绿色 / “已关闭”红色）。
  - 显示目标：destination 为 IP 且 domain 非空时，显示 `domain:port`；否则显示 destination 原文。
- 第二行（caption2 等宽），三列：
  - 活动连接：左列 `↑ <速率>/s`、`↓ <速率>/s`；中列 `<上行总量>`、`<下行总量>`；右列（右对齐）`<inboundType>/<inbound>`、`chain[0]`。
  - 已关闭：左列 `↑ <上行总量>`、`↓ <下行总量>`；中列 创建时间 `HH:mm:ss`、持续时间；右列 `<inboundType>/<inbound>`、链路倒序以 `/` 连接。
  - 中列后有弹性空白。
- 字节格式：与仪表一致的 FormatBytes（第 5 章）。
- 持续时间格式：<1 s → `<毫秒>ms`；<1 min → `<秒>.<百分秒整数>s`（百分秒不补零，例如 1.05 s 显示 `1.5s`，与核心实现一致）；否则 `<分>m<秒>s`。
- 右键菜单：仅活动连接显示“关闭”（破坏性）→ `CloseConnection(id)`，失败动作名 “close connection”。
- 点击：在详情列内推入“连接详情”页（带返回按钮），标题“连接”。

### 8.4.2 连接详情页
分组表单（只读文本行，标签左、值右，值可选中复制）：
- 状态：“活动”/“已关闭”；创建时间（`yyyy-MM-dd HH:mm:ss`）；关闭时间（若已关闭）；上行（总量）；下行（总量）。
- 分节“元数据”：入站、入站类型、IP 版本、网络（大写）、来源、目标、域名（非空时）、协议（非空时）、用户（非空时）、来自出站（非空时）、匹配规则（非空时）、出站、出站类型、链路（链长 >1 时，倒序 `/` 连接）。
- 详情为打开时的快照，不随推送刷新（与基线一致）。
