# 14 错误处理

## 14.1 通用错误对话框
所有页面的操作失败统一使用错误对话框（对应基线 AlertState）：
- 标题：“错误”。
- 正文：`Failed to <动作名>` + 换行 + 错误描述（去首尾空白；描述为空时只有第一行）。动作名为各章列出的英文短语（如 “start service”、“save server”），与基线一致不翻译；错误描述来自守护进程/worker 时已按 `accept-language` 本地化。
  - 可选改进（默认不实现）：动作名本地化，A-20。
- 按钮：“复制”（把正文复制到剪贴板，不关闭）与“好”（关闭）。
- 只有消息无动作名的错误（如“服务未启动”）：正文即消息，按钮同上。
- 信息类对话框（如“检查更新 / 没有可用的更新”）：自定标题，仅“好”。
- 同一时刻只显示一个对话框；新错误在当前对话框关闭后显示（队列）。
- 对话框为窗口模态（MyGo AlertDialog），从托盘触发且主窗口隐藏时使用独立顶层对话框。

## 14.2 错误来源与转换
| 来源 | 处理 |
|---|---|
| gRPC 状态错误 | 描述取 `status.Message()`；P2 上的 `Unavailable` 先按 15.2.1 重新检测服务状态，再映射为 E-DAEMON-01/07/08；`PermissionDenied` 且消息含 owned by another user 映射为 E-DAEMON-03 |
| worker 启动失败 | E-DAEMON-02；stderr 含 “different signing certificates” 时为 E-DAEMON-05 |
| 网络/HTTP（远程配置、更新） | 描述为 `HTTP <状态码>` 或底层错误文本 |
| 配置校验（CheckConfig） | 描述为核心返回原文（含 JSON 路径与行列） |
| 文件 I/O | Windows 错误文本（`FormatMessage`，界面语言） |

## 14.3 守护进程错误码
| 代码 | 条件 | 标题 / 正文 | 按钮与恢复 |
|---|---|---|---|
| E-DAEMON-01 | 服务未安装（`service status` 退出码 3） | 仪表盘显示“服务未安装”状态页（第 5 章），不弹框；操作时弹“错误 / 服务不可用，请安装或修复服务。” | “安装服务”→15.2.3 |
| E-DAEMON-02 | worker 10 秒内未输出 `READY`、首行不符或提前退出 | “错误 / 无法启动服务组件。” + 退出码与 stderr 末尾内容 | “复制”“好”；下次调用自动重试拉起（单飞） |
| E-DAEMON-03 | 服务由其他 Windows 用户拥有 | “服务正被其他用户使用 / 另一个 Windows 用户正在使用 sing-box 服务。接管将停止其连接。” | “接管”（破坏性，`TakeOverService` 后继续原操作）/“取消” |
| E-DAEMON-04 | `GetDaemonInfo.version` ≠ 随附守护进程 `version` 输出 | 仪表盘提示“服务需要修复” | “修复服务”→15.2.3 |
| E-DAEMON-05 | 签名者不一致：GUI 自检发现 `sing-box.exe` 与 `resources\daemon\sing-box-daemon.exe` 的签名证书不同，或 worker 报告签名证书不同 | “错误 / sing-box 的程序文件签名不一致。请重新安装 sing-box。” | “打开下载页”/“好”。常见原因：混装了不同构建方的文件（官方发布与源码构建，21.5） |
| E-DAEMON-06 | 签名证书不在有效期内：GUI 自检发现自身证书当前时间早于 NotBefore 或晚于 NotAfter | 仪表盘提示“此版本的签名证书已过期，请更新 sing-box。”；当前时间早于 NotBefore 时改为“系统时间不正确，请校准时间后重试。” | “检查更新”→12.5（12.5.1）/“好” |
| E-DAEMON-07 | 服务已安装但未运行（退出码 2），或启动服务失败 | 仪表盘显示“服务未运行”状态页；操作时弹“错误 / sing-box 服务未运行。” + Windows 错误文本（如有） | “启动服务”/“修复服务”→15.2.3 |
| E-DAEMON-08 | 服务运行中但守护进程拒绝连接（经中继的连接在建立后立即关闭，且 E-DAEMON-05/06 自检通过） | “错误 / sing-box 服务拒绝了连接。请修复服务；如问题持续，请查看事件查看器中来源为 sing-box-daemon 的日志。” | “修复服务”/“好” |
| E-DAEMON-09 | 安装布局无效：`LayoutVersion` 不是 2，或 GUI 不在 2.6 规定的布局中运行（例如直接运行解压出的文件） | “错误 / sing-box 安装不完整或位置不受支持。请使用安装程序重新安装。” | “好”；开发构建见 18.4 |
| E-SVC-01 | `SubscribeServiceStatus` 报 `FATAL` | “错误 / Failed to start service” + `errorMessage` | 状态回到未连接 |
| E-SVC-02 | 运行中服务意外停止（状态流中断且服务状态为未运行） | 系统通知“sing-box 服务已停止” + 原因 | 托盘与仪表盘更新状态；服务恢复策略会自动重启服务，GUI 重连后若 `started_by_user` 为真不自动重新连接（避免崩溃循环），由用户手动启动 |
| E-UPD-01 | 更新清单签名无效（12.5） | “错误 / Failed to install update” + “更新签名无效，已删除下载的文件。” | “好” |
| E-UPD-02 | 更新文件 SHA-256 或大小与清单不一致 | “错误 / Failed to install update” + “更新文件校验失败，已删除下载的文件。” | “好” |

- GUI 的签名自检（E-DAEMON-05/06）在 `internal/platform/authenticode` 中以与守护进程相同的规则（2.9.4）读取两份可执行文件的签名证书并比较，只用于给出准确的错误提示，不替代守护进程的检查。自检在启动时与每次 worker 启动失败后执行一次。
- E-DAEMON-01（修复失败时）、E-DAEMON-02 与 E-DAEMON-07 的错误详情末尾附加：“如果杀毒软件隔离了 sing-box 的文件，请在核实 SHA-256 后恢复文件并修复服务。”（21.4.3）
- 守护进程拒绝连接的原因只写入 Windows 事件日志（来源 `sing-box-daemon`），不返回给客户端。

## 14.4 启动前检查
按顺序执行，任一失败即中止并提示：
1. 无选中配置：“错误 / 未选择配置”（仪表盘空态已提示，不重复）。
2. 读取配置文件失败：`Failed to read profile`。
3. 应用重载/隧道选项后 `CheckConfig` 失败：`Failed to start service` + 核心错误。
4. 所有权（14.3 E-DAEMON-03）。
5. 弃用警告：启动成功后调用 `GetDeprecatedWarnings`，有警告且未开启“禁用弃用警告”时逐条弹出“弃用警告”对话框（正文为警告文本，按钮“文档”打开迁移文档链接 / “好”），与基线一致。

## 14.5 订阅与流
- 订阅流（状态、分组、日志、连接、Tailscale 等）断开：1 秒后重连，指数退避至最长 10 秒；服务停止时不重连。
- 重连期间页面保持最后数据，日志页不清空；分组/连接页在重新订阅成功后整体替换。
- 远程控制流断开：按 11.8 退出远程模式并提示。

## 14.6 远程配置更新错误
- 手动更新失败：错误对话框（动作名 “update profile”）。
- 自动更新失败：不弹框，不发通知，仅记录 GUI 日志；下次周期重试（6.6.1）。

## 14.7 崩溃与卡死
- GUI 进程：Go panic 与未处理 SEH 异常写入 `%LOCALAPPDATA%\sing-box\Cache\crash\`，下次启动在工具页“崩溃报告”的计数中体现（作为“本机”来源报告，与守护进程报告列表合并显示，A-21）。
- 主线程卡死 > 5 秒：记录卡死报告（kind = Hang）。
- 守护进程/核心崩溃：由守护进程生成报告（第 10.7 节）；守护进程崩溃由服务控制管理器按服务恢复策略重启。

## 14.8 日志
- GUI 自身日志写 `%LOCALAPPDATA%\sing-box\Cache\gui.log`（滚动 5 MB × 3），不在日志页显示（日志页只显示核心日志）。
