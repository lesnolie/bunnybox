# 03 视觉规范

本章定义全应用共用的视觉令牌。所有页面章节中出现的字号、颜色、圆角名称均以本章为准。界面以 macOS 26 上的基线客户端为准：**同一窗口尺寸下，控件位置、尺寸、间距、圆角、字号、颜色与图标含义必须一致**；仅窗口标题栏按钮（最小化/最大化/关闭）与系统菜单遵循 Windows。

## 3.1 单位与缩放
- 所有尺寸单位为 DIP（MyGo 原生 UI 单位），以 SwiftUI 的 pt 数值为初值；最终按锁定截图校准字体度量与布局。
- 跟随 Windows 显示缩放（100%–300%）；不得写死像素。

- 等宽（`.monospaced()`、日志、连接首行、计数胶囊）：Cascadia Mono，缺失时 Consolas。

- 中文/日文/韩文回退：Microsoft YaHei UI / Microsoft JhengHei UI / Yu Gothic UI / Malgun Gothic，由系统回退链处理。
- 波斯语启用 RTL 布局（第 15 章）。
- 字体替换为待定事项 A-05（推荐默认即本表）。

## 3.4 外观模式
- 跟随 Windows“应用模式”浅色/深色，实时切换（MyGo 主题默认行为）。
- 高对比度主题：使用 MyGo `HighContrast` 主题，关闭玻璃材质。

## 3.5 材质与圆角

| 名称 | 规范 |
|---|---|
| cardStyle | `glass.Glass{}` 常规玻璃，圆角 16；若用户在“设置 → 应用”关闭“透明效果”或系统关闭透明效果，则回退为 textBackground 填充 + 圆角 16 |
| selectorBackground | 可交互玻璃，圆角 12；回退为 secondary @ 0.1 |
| ActionIconButton | 44×32，图标 12，背景 secondary @ 0.1，圆角 8，按下缩放 0.94 |
| 分组头部 | 上圆角 16（下方直角）；内容区下圆角 16 |
| 分组项 | 圆角 12 |
| 计数胶囊 | 全圆角（Capsule） |
| 工作表（Sheet） | 圆角 12，居中于主窗口，带遮罩 |

macOS 使用连续曲率圆角（squircle）。MyGo 若提供连续圆角选项则必须启用；否则使用标准圆角（待定 A-06）。

## 3.6 窗口
- 主窗口：`mygo.NewWindow`，`TitleBarStyle` 隐藏标题栏、保留窗口按钮于右上角；工具栏与标题栏合并为一行（对应 macOS 统一工具栏），高 52。
- 侧边栏与应用内弹出窗口采用 MyGo 自绘材质，按锁定 macOS 截图调校；不得默认用 Windows Mica/Acrylic 替换。系统关闭透明效果或高对比度模式下使用本章规定的纯色回退。
- 窗口状态（位置、尺寸、最大化）以 `StateKey: "main"` 记忆，存入 settings.db（`App.SetWindowStateStore`）。

## 3.9 视觉基线与允许差异
- 最终版本验收基线为 1.2 锁定 Apple 提交运行于 macOS 26 的截图，需在 `testdata/screenshots/baseline.json` 固定系统构建号、Apple提交、尺寸、倍率、语言和主题。当前已取得第23章的用户截图及文章1.14.0截图，可据用户确认方向直接开发；尚缺完整版本和系统信息，不编造精确锁定，也不因此阻止近似效果实现。
- 字体与图标使用 3.2、3.8 的替代资源是明确允许的差异，但仍须校准文字换行、基线、图标占位与视觉重量；Windows 10 缺少 Segoe UI Variable 时回退 Segoe UI，并单独验收。不得随附未获许可的 Apple 字体或图标。
- 允许差异：窗口系统按钮、系统文件/权限对话框、字体与图标替代、系统无障碍/关闭透明效果回退、第 15 章列明的平台能力差异。应用内容区布局、配色和交互不得以“Windows 风格”为由另行设计。
- M1 先完成仪表盘、设置表单、弹出菜单三个样板，在浅深色、英文及简体中文下按 20.4 验收后，再扩展到全量页面。框架缺少控件样式时在 MyGo 中自绘或封装，不静默改换前端框架。
